Paste: when iOS shrinks the system Paste button, the app's own takes its place

O que mudou
  • On an iPhone with iOS 26.3.1 the Paste button on the recovery phrase screen vanished, even with a phrase copied: the system PasteButton shrank to zero width (a known iOS issue reported since iOS 17). The simulator did not show it.
  • AppPasteButton keeps the system PasteButton, which pastes without the iOS prompt. If it stays under 8 points wide, an app button with the same label and style replaces it; it reads the clipboard off the main thread, so iOS asks "Allow Paste" first and the screen does not freeze.
  • Used on all five Paste buttons: recovery phrase, Send, Contacts, watch address and custom token. "Colar" translated in the 12 languages.
  • UI test: the app button pastes a 12 word phrase after the iOS prompt.

28 de outubro de 2026

Receipt alerts leave passphrase wallets out again

O que mudou

This reverts 4b5f68d on iOS and Android. The alert file opens after the first unlock, outside the encrypted wallet data, so with a passphrase wallet in it anyone who extracts the phone's data in that state finds the wallet the owner chose to hide. The wallet list itself needs the PIN; the alert file does not. The privacy policy and the security notes already said these wallets stay out, and now the code agrees. The trade-off is that a passphrase wallet does not notify when funds arrive.

Found in the security review of Android 1008 (28/10/2026).

Vault: a locked key is not a wrong PIN, and Forgot PIN waits 24 hours

O que mudou
  • A password key that is locked (device not yet unlocked) now reports "locked" instead of a failed PIN: the attempt is refunded and the counter does not move. Covers the PIN slot, biometry and Super Security.
  • Android vault format 2: the PIN key no longer carries the password in the AAD. Legacy items are read as before and migrated on a correct read. Invalidated keys are no longer deleted while probing; confirmation is required on biometric keys.
  • Forgot PIN asks first and erases only after 24 hours. Unlocking with the PIN or biometry cancels the request. A lost Super Security vault still erases at once. Same flow on iOS and Android.
